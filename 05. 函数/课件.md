# Python函数

## 函数定义

函数是组织好的、可重复使用的代码块，用于执行特定任务。

```python
# 定义函数
def greet():
    print("Hello, World!")

# 调用函数
greet()  # 输出: Hello, World!
```

### 函数结构

```python
def 函数名(参数1, 参数2, ...):
    """文档字符串（可选）"""
    # 函数体
    return 返回值  # 可选
```

```python
# 带返回值的函数
def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 8

# 无返回值的函数（默认返回None）
def say_hello():
    print("Hello")

result = say_hello()
print(result)  # None
```

## 函数参数

### 位置参数

按位置顺序传入的参数，必须一一对应。

```python
def greet(name, age):
    print(f"{name}今年{age}岁")

greet("Alice", 25)      # Alice今年25岁
greet("Bob", 30)        # Bob今年30岁
```

### 默认参数

在定义时给参数指定默认值，调用时可以不传。

```python
def greet(name, greeting="你好"):
    print(f"{greeting}, {name}!")

greet("Alice")              # 你好, Alice!
greet("Bob", "早上好")       # 早上好, Bob!
```

**注意：** 默认参数必须放在非默认参数之后。

```python
# 正确
def func(a, b=2, c=3):
    pass

# 错误（会报错）
# def func(a=1, b, c=3):
#     pass
```

### 关键字参数

调用时通过 `参数名=值` 的方式传入，可以不按顺序。

```python
def greet(name, age, city):
    print(f"{name}今年{age}岁，住在{city}")

# 关键字参数
greet(name="Alice", age=25, city="北京")
greet(age=25, city="北京", name="Alice")  # 顺序无关
greet("Alice", age=25, city="北京")        # 混合使用（位置参数在前）
```

### 可变参数 *args

接收任意数量的位置参数，在函数内部作为**元组**处理。

```python
def total(*numbers):
    result = 0
    for n in numbers:
        result += n
    return result

# 调用
print(total())           # 0
print(total(1, 2, 3))    # 6
print(total(1, 2, 3, 4, 5))  # 15

# 也可以用列表/元组展开
data = [1, 2, 3, 4]
print(total(*data))      # 10（* 用于展开序列）
```

### 可变关键字参数 **kwargs

接收任意数量的关键字参数，在函数内部作为**字典**处理。

```python
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

# 调用
print_info(name="Alice", age=25, city="北京")
# 输出:
# name: Alice
# age: 25
# city: 北京

# 也可以用字典展开
data = {"name": "Bob", "age": 30}
print_info(**data)  # ** 用于展开字典
```

### 参数顺序规则

定义函数时，参数必须按以下顺序：

| 顺序 | 参数类型 | 示例 |
|------|---------|------|
| 1 | 位置参数 | `def func(a, b)` |
| 2 | 默认参数 | `def func(a, b=2)` |
| 3 | *args | `def func(a, *args)` |
| 4 | **kwargs | `def func(a, **kwargs)` |

```python
def func(a, b=2, *args, **kwargs):
    print(f"a={a}, b={b}")
    print(f"args={args}")
    print(f"kwargs={kwargs}")

func(1, 2, 3, 4, x=5, y=6)
# 输出:
# a=1, b=2
# args=(3, 4)
# kwargs={'x': 5, 'y': 6}
```

### 强制关键字参数

在 `*args` 之后或使用单独的 `*` 的参数，必须通过关键字传入。

```python
def greet(name, *, greeting="你好", punctuation="!"):
    print(f"{greeting}, {name}{punctuation}")

greet("Alice")                           # 你好, Alice!
greet("Bob", greeting="早上好")            # 早上好, Bob!
greet("Carol", punctuation=".")          # 你好, Carol.
# greet("Dave", "晚上好")  # 报错！greeting必须通过关键字传入
```

## 返回值

### 单一返回值

```python
def square(x):
    return x * x

result = square(5)
print(result)  # 25
```

### 多返回值

Python函数可以返回多个值，实际上是返回一个**元组**。

```python
def calc(a, b):
    return a + b, a - b, a * b

# 解包赋值
sum_val, diff, product = calc(10, 3)
print(sum_val)    # 13
print(diff)       # 7
print(product)    # 30

# 也可以作为一个整体接收
result = calc(10, 3)
print(result)     # (13, 7, 30)
print(type(result))  # <class 'tuple'>
```

### 无返回值

函数没有 `return` 语句，或只有 `return` 时，返回 `None`。

```python
def log(message):
    print(f"[LOG] {message}")
    return  # 显式返回None

def log2(message):
    print(f"[LOG] {message}")
    # 没有return，隐式返回None

print(log("test"))   # None
print(log2("test"))  # None
```

## 变量作用域

### 局部变量与全局变量

```python
name = "Global"  # 全局变量

def func():
    name = "Local"  # 局部变量（与全局变量同名）
    print(name)     # Local

func()
print(name)         # Global
```

### global关键字

在函数内部声明使用全局变量。

```python
count = 0

def increment():
    global count
    count += 1
    print(count)

increment()  # 1
increment()  # 2
print(count)  # 2
```

### nonlocal关键字

在嵌套函数中，修改外层（非全局）函数的变量。

```python
def outer():
    x = 10
    
    def inner():
        nonlocal x  # 声明使用外层函数的x
        x = 20
        print(f"inner: {x}")
    
    inner()
    print(f"outer: {x}")

outer()
# 输出:
# inner: 20
# outer: 20
```

| 关键字 | 作用 |
|--------|------|
| `global` | 声明使用全局变量 |
| `nonlocal` | 声明使用外层（非全局）函数的变量 |

## lambda表达式

lambda是创建小型匿名函数的简洁方式。

```python
# 普通函数
def add(x, y):
    return x + y

# 等价的lambda
add = lambda x, y: x + y

print(add(3, 5))  # 8
```

**使用场景：** 作为简短的一次性函数传递。

```python
# 列表排序
students = [("Alice", 25), ("Bob", 20), ("Carol", 23)]
students.sort(key=lambda x: x[1])  # 按年龄排序
print(students)  # [('Bob', 20), ('Carol', 23), ('Alice', 25)]

# map函数
numbers = [1, 2, 3, 4]
squares = list(map(lambda x: x ** 2, numbers))
print(squares)  # [1, 4, 9, 16]

# filter函数
evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens)  # [2, 4]
```

**限制：** lambda只能包含单个表达式，不能包含语句（如赋值、循环等）。

## 内置函数

Python提供了丰富的内置函数，以下是常用的几个：

| 函数 | 说明 | 示例 |
|------|------|------|
| `len()` | 返回对象长度 | `len("hello")` → `5` |
| `range()` | 生成整数序列 | `range(5)` → `0,1,2,3,4` |
| `enumerate()` | 带索引的迭代 | `enumerate(["a","b"])` → `(0,"a"),(1,"b")` |
| `zip()` | 并行迭代多个序列 | `zip([1,2],["a","b"])` → `(1,"a"),(2,"b")` |
| `map()` | 对每个元素应用函数 | `map(str, [1,2])` → `["1","2"]` |
| `filter()` | 按条件过滤 | `filter(lambda x: x>0, [-1,1])` → `[1]` |
| `sorted()` | 排序 | `sorted([3,1,2])` → `[1,2,3]` |
| `sum()` | 求和 | `sum([1,2,3])` → `6` |
| `max()` | 最大值 | `max([1,3,2])` → `3` |
| `min()` | 最小值 | `min([1,3,2])` → `1` |
| `abs()` | 绝对值 | `abs(-5)` → `5` |
| `round()` | 四舍五入 | `round(3.7)` → `4` |
| `type()` | 返回类型 | `type(42)` → `<class 'int'>` |
| `isinstance()` | 类型检查 | `isinstance(42, int)` → `True` |

```python
# enumerate示例
names = ["Alice", "Bob", "Carol"]
for index, name in enumerate(names):
    print(f"{index}: {name}")
# 输出:
# 0: Alice
# 1: Bob
# 2: Carol

# zip示例
names = ["Alice", "Bob", "Carol"]
ages = [25, 30, 23]
for name, age in zip(names, ages):
    print(f"{name}: {age}")
# 输出:
# Alice: 25
# Bob: 30
# Carol: 23

# sorted示例
numbers = [3, 1, 4, 1, 5]
print(sorted(numbers))          # [1, 1, 3, 4, 5]
print(sorted(numbers, reverse=True))  # [5, 4, 3, 1, 1]
```

## 函数文档

使用文档字符串（docstring）为函数添加说明。

```python
def calculate_bmi(weight, height):
    """
    计算BMI指数
    
    参数:
        weight: 体重（千克）
        height: 身高（米）
    
    返回:
        BMI数值
    """
    return weight / (height ** 2)

# 查看文档
print(calculate_bmi.__doc__)

# help函数查看完整信息
help(calculate_bmi)
```

## 类型注解

Python 3.5+ 支持类型注解，用于提示参数和返回值的类型（不影响运行）。

```python
def greet(name: str, age: int) -> str:
    return f"{name}今年{age}岁"

# 带默认值的类型注解
def add(a: int, b: int = 0) -> int:
    return a + b

# 复杂类型
from typing import List, Dict

def process(data: List[int]) -> Dict[str, int]:
    return {"count": len(data), "sum": sum(data)}
```

**注意：** 类型注解只是提示，Python不会强制执行类型检查。

```python
def add(a: int, b: int) -> int:
    return a + b

# 传入字符串也不会报错
print(add("Hello, ", "World!"))  # Hello, World!
```
