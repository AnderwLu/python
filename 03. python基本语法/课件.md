# Python基本语法

## 1. 注释

```python
# 单行注释

"""
多行注释
文档字符串（Docstring）
"""

'''
也可以用单引号
'''
```

## 2. 变量与赋值

```python
# 动态类型，无需声明
name = "Alice"
age = 25
pi = 3.14
is_valid = True

# 多重赋值
a = b = c = 0
x, y, z = 1, 2, 3

# 变量命名：字母/下划线开头，区分大小写
# 规范：snake_case
```

## 3. 基本数据类型

```python
# 数字
num = 42          # int
price = 19.99     # float
complex_num = 3+4j # complex

# 字符串（不可变）
s = "Hello"
s = 'World'
s = """多行
字符串"""

# 字符串操作
s[0]        # 'H'（索引）
s[1:4]      # 'ell'（切片）
s + "!"     # 拼接
f"Hi {name}" # f-string格式化
len(s)      # 长度

# 布尔值
flag = True  # 或 False

# 空值
result = None
```

## 4. 数据结构

### 列表（List）

```python
# 有序、可变、可重复
arr = [1, 2, 3, "a", "b"]
arr[0]      # 1
arr[-1]     # "b"（倒数第一个）
arr[1:3]    # [2, 3]（切片）
arr.append(4)
arr.extend([5, 6])
arr.insert(0, 0)
arr.remove("a")
arr.pop()       # 移除并返回最后一个
len(arr)
```

### 字典（Dict）

```python
# 键值对，键必须不可变
user = {"name": "Alice", "age": 25}
user["name"]           # "Alice"
user.get("gender", "N/A")  # "N/A"（安全取值）
user["age"] = 26
user.keys()
user.values()
user.items()
"name" in user         # True
```

### 元组（Tuple）

```python
# 有序、不可变
t = (1, 2, 3)
t[0]        # 1
# t[0] = 4  # 报错！不可变
```

### 集合（Set）

```python
# 无序、不重复
s = {1, 2, 3}
s.add(4)
s.remove(2)
s1 & s2     # 交集
s1 | s2     # 并集
s1 - s2     # 差集
```

## 5. 运算符

```python
# 算术
+  -  *  /  //（整除）  %（取余）  **（幂）

# 比较
==  !=  >  <  >=  <=

# 逻辑
and  or  not

# 成员
in  not in

# 身份
is  is not    # 比较对象标识（id），非值

# 赋值
=  +=  -=  *=  /=
```

## 6. 输入输出

```python
# 输出
print("Hello")
print(a, b, c, sep="-")
print("Done", end="!")

# 输入（返回字符串）
name = input("请输入名字：")
age = int(input("请输入年龄："))

# f-string（推荐）
name = "Alice"
age = 25
print(f"{name}今年{age}岁")
```

## 7. 条件语句

```python
# if / elif / else
if age > 18:
    print("成年")
elif age > 12:
    print("青少年")
else:
    print("儿童")

# 三元表达式
status = "成年" if age >= 18 else "未成年"
```

## 8. 循环

```python
# for 循环
for i in range(5):      # 0,1,2,3,4
    print(i)

for item in ["a", "b", "c"]:
    print(item)

# while 循环
n = 0
while n < 5:
    print(n)
    n += 1

# 控制
break       # 终止循环
continue    # 跳过本次

# 列表推导式
squares = [x**2 for x in range(5)]        # [0, 1, 4, 9, 16]
evens = [x for x in range(10) if x % 2 == 0]
```

## 9. 函数

```python
# 定义
def greet(name):
    """函数文档字符串（可选）"""
    return f"Hello, {name}"

# 调用
msg = greet("Alice")

# 参数类型
def demo(a, b=10, *args, **kwargs):
    """
    a: 位置参数
    b=10: 默认参数
    *args: 可变位置参数（元组）
    **kwargs: 可变关键字参数（字典）
    """
    pass

demo(1)                 # a=1, b=10
demo(1, 2)              # a=1, b=2
demo(1, 2, 3, 4)        # args=(3, 4)
demo(1, x=10, y=20)     # kwargs={"x": 10, "y": 20}

# lambda
add = lambda x, y: x + y
print(add(1, 2))        # 3
```
