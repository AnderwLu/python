# Python基本语法文档设计

## 目标读者
有编程基础（前端/后端经验），但Python零基础的工作人士

## 设计风格
速查表式：极度简洁，只列要点和代码示例，不做冗余解释

## 内容结构
1. 注释 - 单行/多行/文档字符串
2. 变量与赋值 - 命名规则、动态类型、多重赋值
3. 基本数据类型 - 数字、字符串、布尔、None
4. 数据结构 - 列表、字典、元组、集合
5. 运算符 - 算术、比较、逻辑、成员/身份
6. 输入输出 - print/input
7. 条件语句 - if/elif/else
8. 循环语句 - for/while/break/continue
9. 函数定义 - def/return/参数

## 格式规范
- 每个语法点只保留核心代码示例
- 使用代码块展示语法
- 不加长篇解释，必要处用单行注释
